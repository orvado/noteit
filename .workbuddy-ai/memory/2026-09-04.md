## Fix dark mode dropdown menu (b6ce50d)

- Problem: WPF default MenuItem template hardcodes light-gray popup background;
  in dark mode the dropdown menus stayed light gray, making text hard to read
- Fix: Replaced default MenuItem template with a custom ControlTemplate that
  uses DynamicResource brushes for popup background, hover highlight, borders,
  and disabled item foreground. Added 5 new themed brushes:
  NoteItMenuPopupBackground, NoteItMenuPopupForeground, NoteItMenuItemHoverBackground,
  NoteItMenuItemHoverForeground, NoteItMenuItemBorder
- Dark mode popup background is now #1F1F1F (near-black), hover is #2F2F2F
- Also added custom Separator template themed via NoteItSeparator brush
- Build: 0 warnings, 0 errors
